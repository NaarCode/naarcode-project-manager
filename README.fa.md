# NaarCode Project Manager

**مدیریت پروژه، کنترل کیفیت و پیگیری اجرا در یک محیط عملیاتی.**

[English](README.md) · [معماری](docs/ARCHITECTURE.fa.md) · [ملاحظات امنیتی](docs/SECURITY.fa.md)

NaarCode Project Manager یک سامانه داخلی برای برنامه‌ریزی، اجرای پروژه و کنترل کیفیت در فرایند تولید محصولات دیجیتال است. این سامانه برای پیگیری وضعیت پروژه‌ها، مسئولیت‌ها، چک‌لیست‌های اجرایی و گزارش فعالیت در یک فضای واحد طراحی شده است.

> **درباره این مخزن:** این مخزن یک معرفی فنی و محصولی است؛ سورس سامانه عملیاتی، اطلاعات کاربران و تنظیمات زیرساخت در آن منتشر نشده‌اند. نمودارها صرفاً ساختار سامانه را توضیح می‌دهند و اسکرین‌شات محصول نیستند.

## مسئله

اجرای هم‌زمان چند پروژه فقط به فهرست وظایف نیاز ندارد. مراحل تحویل، معیارهای کیفیت، مالکیت فعالیت‌ها و مسیر تصمیم‌گیری باید در طول چرخه پروژه روشن و قابل پیگیری باقی بمانند. این سامانه برای یکپارچه‌کردن همین بخش‌ها ساخته شده است.

## قابلیت‌های پیاده‌سازی‌شده

- مدیریت پروژه و اعضا همراه با نقش‌های **مدیر کل، مدیر پروژه و عضو**
- ایجاد پروژه با راهنمای مرحله‌ای پنج‌گانه و انتخاب نوع پروژه و ماژول‌ها
- چک‌لیست‌های پویا با منطق **Core + Project Type + Modules → Project Snapshot**
- کتابخانه ۴۳۵ آیتمیِ چک‌لیست و نگهداری نسخه مستقل چک‌لیست در هر پروژه
- محاسبه میزان پیشرفت و امتیاز کیفیت در سمت سرور
- یادداشت‌ها، رویدادها، فعالیت‌ها، اعلان‌ها و نقاط عطف پروژه
- مدیریت فایل و دسترسی کنترل‌شده بر اساس عضویت و نقش
- رابط فارسی، راست‌به‌چپ و واکنش‌گرا

## یک تصمیم مهم در طراحی

قالب چک‌لیست هنگام ساخت پروژه به یک **Snapshot مستقل** تبدیل می‌شود. بنابراین اصلاح قالب‌های اصلی، وضعیت پروژه‌هایی را که از قبل ساخته شده‌اند ناخواسته تغییر نمی‌دهد. این تفکیک، پیگیری کیفیت را در پروژه‌های طولانی‌مدت قابل اتکاتر می‌کند.

شاخص پیشرفت، سهم آیتم‌های تکمیل‌شده از آیتم‌های قابل اجراست؛ آیتم‌های «نامرتبط» در مخرج وارد نمی‌شوند. امتیاز کیفیت با وزن آیتم‌ها محاسبه می‌شود و قواعد دسترسی و اعتبارسنجی در سمت سرور اعمال می‌شوند.
