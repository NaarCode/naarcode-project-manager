# Public repository security note

This repository contains documentation and a conceptual architecture diagram only. No production code, credentials, authentication secrets, user records, environment files, deployment details, or database exports are included.

Security claims here describe implementation intent and source-reviewed mechanisms; they are **not** a penetration-test certificate or an independent production security audit.

If you identify a security issue, report it privately through the contact details on [naarcode.com](https://naarcode.com/fa). Do not disclose working exploits or private user information in public issues.
